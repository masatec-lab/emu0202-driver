# E-MU 0202 USB: драйвер для macOS на Apple Silicon

Драйвер E-MU 0202 USB (041e:3f02) для современных macOS, включая Apple Silicon. Работает без расширений ядра (kext) и не требует отключать защиту системы (SIP). Это плагин Core Audio, который общается с картой через IOUSBHost.

Сейчас умеет: полный дуплекс, то есть одновременно стерео-выход и стерео-вход на общих часах карты. Это нужно для записи и для игры на гитаре через плагины-симуляторы в DAW. 24 бит, частоты 44,1, 48, 88,2 и 96 кГц.

Задержка откалибрована кабелем-петлёй (выход R → вход R, `build/looptest`): путь «выход → карта → вход» занимает около 7,4 мс, и драйвер сообщает это программам, так что DAW ставят записанное точно на место. Полная задержка «туда-обратно» при игре через плагин в DAW — это 7,4 мс плюс два буфера и 4,75 мс запаса драйвера: около 13,7 мс при буфере 32 на 44,1 кГц, 15 мс при 64, 18 мс при 128.

Входы: Input 1 — левое гнездо (L, Mic/Hi-Z/Line), Input 2 — правое (R, Hi-Z/Line).

Громкость выхода регулируется системным ползунком и клавишами громкости Mac, там же работает выключение звука. Регулятор программный: он ослабляет звук до отправки на карту, поэтому влияет на всё, что играет через карту, включая DAW. Прямой мониторинг входа и ручки на самой карте работают как раньше. Значения запоминаются между перезапусками.

Пока не умеет: частоты 176,4 и 192 кГц.

Первый запуск звука после подключения карты или смены частоты занимает около 0,3 с: драйвер проигрывает короткую тишину и перезапускает поток. Без этого карта в первом потоке на новой частоте могла уйти в другое состояние буфера, и задержка отличалась от откалиброванной на 1–4 мс.

## Установка

```
./build.sh       # собрать
./install.sh     # установить (попросит пароль администратора)
```

Затем выберите «E-MU 0202 | USB» в «Системные настройки → Звук → Выход».

Удаление: `./uninstall.sh`

## Диагностика

Журнал драйвера:
```
/usr/bin/log show --last 5m --style compact --predicate 'subsystem == "ru.masatec.emu0202"'
```
Раз в 10 секунд во время воспроизведения в журнал пишется строка `stats:`. Если всё в порядке, `errors`, `resyncs`, `underruns` и `late` равны нулю.

Используйте полный путь `/usr/bin/log`: в zsh просто `log` — это встроенная команда оболочки.

Проверка без установки, когда плагин в систему не поставлен:
```
build/emutest --seconds 10                # поток тишины в обе стороны, выводит статистику
build/emutest --seconds 5 --tone          # тихий тон 440 Гц
build/emutest --seconds 30 --monitor      # вход 1 сразу на выход: игра на гитаре через драйвер
build/emutest --buffer 64 ...             # размер буфера, по умолчанию 128
```

## Как устроено

- `src/EMUEngine.m` — USB-движок, работает в трёх потоках.
  - **Поток постановки** держит передачи в очереди на 24 мс вперёд. Только он вызывает IOUSBHost во время работы, а такие вызовы иногда блокируются примерно на 10 мс.
  - **Поток реального времени** работает без системных вызовов. Он записывает звук в выходной пакет за 3 мс до отправки: буферы отображены для DMA, и контроллер читает их в момент передачи. Он же забирает пришедшие входные пакеты, опрашивая список транзакций в памяти, общей с ядром (`KernelUserShared`): пакет виден через 0,2–0,3 мс после своего кадра.
  - **Обработчики завершения** приходят с опозданием до 15 мс, поэтому они только возвращают буферы в пул.
- `src/EMU0202Driver.c` — плагин Core Audio (AudioServerPlugIn): устройство, поток, свойства, ввод-вывод.
- `docs/descriptors.txt` — USB-дескрипторы карты.
- `tools/` — пробные утилиты: `emudesc.c` (дескрипторы), `emuplay.c` (первая проверка на libusb), `clockprobe.m` (USB-часы против системных), `inprobe.m` (насколько рано видны входные пакеты), `emutest.m` (движок без Core Audio), `plugintest.c` (плагин с имитацией хоста), `controltest.c` (регуляторы громкости и выключения звука, без запуска звука: `build/controltest build/EMU0202.driver`), `looptest.c` (замер задержки кабелем-петлёй с выхода R на вход R: `build/looptest [частота] [прогонов] [буфер]`, показывает неучтённую драйвером часть, после калибровки около нуля), `engloop.m` (такой же замер на самом движке без Core Audio, чтобы проверять изменения без установки: `build/engloop --rate 44100 --runs 4 [--switch 48000]`; карта не должна быть занята установленным драйвером).

## Протокол карты

- Внутри это USB Audio Class 1.0 на high-speed, но интерфейсы помечены как vendor-specific (класс 0xFF). Поэтому встроенный аудиодрайвер macOS карту не подхватывает.
- Частота задаётся командой SET_CUR (bmRequestType 0x21, bRequest 0x01), wValue 0x0300, wIndex 0x0c00, 1 байт: 0 = 44,1, 1 = 48, 2 = 88,2, 3 = 96, 4 = 176,4, 5 = 192 кГц.
- Воспроизведение: интерфейс 1, режимы 1/3/5/7 соответствуют 44,1/48/88,2/96 кГц. Конечная точка 0x01 (изохронная, асинхронная), обратная связь через 0x81: число сэмплов на кадр 1 мс в формате 16.16.
- Запись: интерфейс 2, конечная точка 0x82.
